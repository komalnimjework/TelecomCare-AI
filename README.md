# TelecomCare AI

Agentic AI-Based IT Ticket Automation System

## Objective
Automate IT ticket classification, troubleshooting,
resolution, and escalation using Agentic AI and RAG.

## Technology Stack
- Python
- FastAPI
- Streamlit
- LangGraph
- Ollama
- ChromaDB
- SQLite

## Key Features
- Intelligent ticket classification
- RAG-based knowledge retrieval
- Agentic workflow orchestration
- Guardrails and human approval
- Cost optimization
- Evaluation and monitoring
